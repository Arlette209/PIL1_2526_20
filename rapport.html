Présentation du rôle

Dans le cadre du projet IFRI_MentorLink, j'ai occupé le rôle de M6 — Développeur Frontend Accès & Profil. Ma mission principale était de concevoir et développer les interfaces graphiques permettant aux utilisateurs d'accéder à l'application et de gérer leur profil.

Mon travail constitue le premier point de contact entre l'utilisateur et l'application. Sans ces pages, aucun utilisateur ne peut accéder aux fonctionnalités de mentorat.

Pages développées

Page de connexion — connexion.html

Page permettant aux utilisateurs enregistrés de se connecter à leur compte via leur email ou numéro de téléphone.

  • Champ identifiant (email ou téléphone)
  • Champ mot de passe avec bouton afficher/masquer
  • Validation des champs avec messages d'erreur
  • Lien mot de passe oublié
  • Bouton connexion avec Google
  • Redirection vers profil.html après connexion

Page d'inscription — inscription.html

Page permettant aux nouveaux utilisateurs de créer un compte en 4 étapes progressives.

  • Étape 1 : Informations personnelles
  • Étape 2 : Profil académique (filière, niveau, compétences)
  • Étape 3 : Disponibilités habituelles
  • Étape 4 : Récapitulatif et confirmation
  • Validation de tous les champs à chaque étape

Page de profil — profil.html

Page permettant à l'utilisateur connecté de consulter et modifier ses informations de profil.

  • Sidebar de navigation
  • Affichage des informations personnelles
  • Affichage des compétences et lacunes sous forme de tags
  • Affichage des disponibilités habituelles
  • Mode édition avec sauvegarde
  • Upload et prévisualisation de photo de profil

Technologies utilisées

HTML5 CSS3 JavaScript Vanilla Bootstrap 5 Google Fonts

Toutes les pages sont développées en HTML/CSS/JS pur sans framework JavaScript, conformément aux spécifications techniques du projet. Bootstrap 5 est utilisé via CDN pour la gestion de la grille responsive.

Points d'intégration avec le backend

Les pages frontend sont prêtes à être connectées aux APIs développées par les membres backend.

connexion.html → API de M2

fetch('/api/login', { method: 'POST', body: JSON.stringify({ identifiant, password }) })

inscription.html → API de M2

fetch('/api/register', { method: 'POST', body: JSON.stringify({ nom, prenom, email, tel }) })

profil.html → API de M3

fetch('/api/profil/update', { method: 'PUT', body: JSON.stringify({ prenom, nom, email }) })

Difficultés rencontrées

  • Live Server : fichier reconnu comme Plain Text. Résolu en changeant le type de fichier dans VS Code.
  • Git : non reconnu dans PowerShell. Résolu en utilisant Git Bash directement.
  • GitHub : URL du dépôt incorrecte. Résolu avec git remote set-url origin.
