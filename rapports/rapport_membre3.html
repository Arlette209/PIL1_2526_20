Projet : IFRI MentorLink

Rôle : Back-end – Persistance des profils utilisateur

1. Description du module

Mon module gère la persistance des profils utilisateur de l'application IFRI MentorLink. Il permet de créer, lire et modifier les informations du profil d'un utilisateur, notamment ses compétences, ses lacunes, ses disponibilités et sa photo de profil.

2. Technologies utilisées

  • Python
  • Flask
  • pymysql
  • MySQL
  • Postman (pour les tests)

3. Architecture du module

Mon module est organisé en 4 fichiers :

  • app.py → Point d'entrée de l'application
  • models.py → Accès à la base de données
  • controllers.py → Logique métier
  • routes.py → Définition des endpoints

4. Endpoints développés

Méthode Endpoint Description
GET /profile/<user_id> Récupère le profil complet d'un utilisateur
PUT /profile/<user_id> Modifie les informations du profil
GET /competences/<user_id> Récupère les compétences d'un utilisateur
PUT /competences/<user_id> Modifie les compétences d'un utilisateur
GET /disponibilites/<user_id> Récupère les disponibilités d'un utilisateur
PUT /disponibilites/<user_id> Modifie les disponibilités d'un utilisateur
GET /lacunes/<user_id> Récupère les lacunes d'un utilisateur
PUT /lacunes/<user_id> Modifie les lacunes d'un utilisateur
POST /profile/<user_id>/photo Upload la photo de profil
